# Changelog

## 0.1.0

Initial version. Published and maintained by 404 Builds.

- Standalone host CLI generates deterministic module/class field metadata from
  explicit source roots, with exclusions, timeout, and freshness checks.
- MicroPython runtime supports documented construction/default/factory, equality,
  frozen, custom-method, post-init, and inheritance behavior.
- Isolated discovery and scoped call-time validation preserve native behavior
  for imported dependencies while rejecting unsupported consumer options.
- Native-reference comparison matrix and optimization-resistant verification,
  including actual MicroPython Windows tests and independent Unix-port audit evidence.
- Host CLI and device runtime packaged together under the MIT License.

See [README.md](README.md) for supported behavior and known limitations.
