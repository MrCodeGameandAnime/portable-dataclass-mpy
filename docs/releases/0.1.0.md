# Portable Dataclass MPY 0.1.0

Initial version, published by **404 Builds**. Original author: **MrCodeGameAndAnime**.

## Included

- CPython CLI for generating deterministic dataclass field manifests, with scan
  roots, exclusions, configurable timeout, and freshness checks.
- MicroPython runtime supporting construction, defaults, factories, equality,
  frozen classes, inheritance, custom methods, and post-init hooks in the supported subset.
- Runnable example with a host preparation script.
- MIT License. Copyright 2026 MrCodeGameAndAnime.

The host package uses native CPython dataclasses. Deploy the included overlay
only on MicroPython.

See the [README](../README.md) for installation, supported behavior, and limitations,
and the [qualification summary](../qualification-summary.md) for recorded test evidence.
